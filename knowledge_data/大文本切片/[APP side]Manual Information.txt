# [APP side]Download and install the app.
## [APP side]Download and install the app.->Note
+ Mobile operating system requirements: Android 8.0, iOS 11.0 and above.
+ In order to ensure the stability of various functions, it is recommended to use versions of Android 8.0, iOS 11.0 and above
+ Mobile phone (iOS end point supports iPhone SE and later models, recommended to use iPhone X and later models).
+ The phone supports internet connection.
+ The phone supports WLAN function.
+ The router supports the 2.4GHz wireless band, and the WLAN signal covers the device's location.
