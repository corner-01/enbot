# [WEB side]Manual Information
## [WEB side]Manual Information->Target Reader
This manual is intended to guide business users who use the EnValt iEnOS Cloud monitoring platform to monitor, set up, and control EnValt devices. Readers need to have basic Internet knowledge and understand the product functions of EnValt device. Please read this manual carefully before using EnValt iEnOS Cloud.

## <font style="color:rgb(0, 0, 0);">[WEB side]Manual Information->Account Type</font>
<font style="color:rgb(0, 0, 0);">There are four types of user accounts: </font>**<font style="color:rgb(0, 0, 0);">general distributor, distributor, installer, and end user.</font>**

<font style="color:rgb(0, 0, 0);">The </font>**<font style="color:rgb(0, 0, 0);">general distributor</font>**<font style="color:rgb(0, 0, 0);"> can create acount for distributor, installer, and end user, as well as view the belonging station and account. The general distributor has the authority to control and upgrade individual/batch devices under their management.</font>

<font style="color:rgb(0, 0, 0);">The</font>**<font style="color:rgb(0, 0, 0);"> distributor</font>**<font style="color:rgb(0, 0, 0);"> can create account for installer, and end user, as well as view the belonging station and account , etc. The distributor has the authority to control and upgrade individual devices under their management.</font>

<font style="color:rgb(0, 0, 0);">The </font>**<font style="color:rgb(0, 0, 0);">installer</font>**<font style="color:rgb(0, 0, 0);"> can assist the end user in creating/managing a station, manage users and organizations, and set grid-related parameters and advanced parameters, etc. The installer has the authority to control and upgrade individual devices under their management.</font>

<font style="color:rgb(0, 0, 0);">The </font>**<font style="color:rgb(0, 0, 0);">end user</font>**<font style="color:rgb(0, 0, 0);"> can view the real-time data of their own station, and contact some basic setting of the devices.</font>

#### [WEB side]Instructions->Maintenance->Intelligent Strategy->Strategy in Germany
This strategy is specifically developed for the Germany.

The German strategy is a specialized strategy for home energy storage systems, designed specifically for the Dutch market.** Once enabled, inverter will apply auto running logic throughout the day.**

Every day, we gather information on the next day's electricity wholesale prices and use these to delineate **high** and **low pricing periods**. 

##### [WEB side]Instructions->Maintenance->Intelligent Strategy->Strategy in Netherlands ->Instructions->Maintenance->Intelligent Strategy->Strategy in Germany->Single optimization
Click set, the control items of the battery will be displayed in the right drawer bar. Set the necessary parameter, and click confirm, the German strategy would be set on the inverter.
