# 公开发布检查

本仓库只允许公开技术实现，不允许公开业务数据或运行产物。

## 禁止提交

- 真实 `.env`、API Key、Token、密码、私有端点和机器人凭据；
- 公司知识库、产品 Q&A、内部文档和原始附件；
- 训练集、验证集、测试集、holdout、人工复核表和逐样本评测输出；
- 模型权重、Embedding/Reranker、LoRA adapter、GGUF 文件；
- Milvus/Redis/SQLite 数据、日志、缓存、临时文件和虚拟环境。

## 提交前检查

1. 确认工作目录是公开快照，而不是公司仓库的历史目录。
2. 查看 `git status --ignored`，确认所有数据与模型都被忽略。
3. 扫描常见密钥格式、邮箱、本机绝对路径和大文件。
4. 运行测试。
5. 使用 `git ls-files` 再次检查最终提交清单。

仓库中的 `.env.example` 只能保留变量名和无敏感性的默认值。
